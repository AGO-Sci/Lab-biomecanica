# Laboratorio de Biomecánica y Desempeño Humano

Primera versión del sitio institucional del laboratorio de la Universidad Central de Chile.

## Publicar en GitHub Pages

1. Subir `index.html` a la **raíz** del repositorio `AGO-Sci/lab-biomecanica` (no dentro de una carpeta adicional).
2. Abrir **Settings → Pages**.
3. En **Build and deployment**, elegir **Deploy from a branch**.
4. Elegir rama `main` y carpeta `/(root)` y presionar **Save**.
5. Cuando finalice la publicación, abrir `https://ago-sci.github.io/lab-biomecanica/`.

## Actualizar el sitio

- El sitio está contenido en un único archivo `index.html`.
- Las traducciones se encuentran al final, dentro del objeto `translations.en`.
- Los recuadros para fotografías son provisionales y se reemplazarán cuando existan imágenes autorizadas.
- No publicar información personal de estudiantes ni fotografías sin las autorizaciones correspondientes.

Esta es una maqueta funcional inicial; los contenidos institucionales definitivos deberán revisarse antes de su difusión oficial.
